Abstract

Research projects that explore different model architectures — autoregressive LLMs, VLMs, world models, diffusion models — typically duplicate scaffolding code: training loops, config validation, dataset streaming, logging, checkpointing. HaleBlocks is a small library that eliminates this duplication by providing the shared primitives as composable plugins behind a unified registry interface.

Imported as hale_core, the library provides attention modules (MHA, GQA, MQA), FFN blocks (MLP, GeGLU, DeepSeekMoE), transformer stacks (GPT-style causal, LGT local-global, DiT adaLN-Zero), token backbones, a flexible loss registry, a pydantic-validated YAML config system with inherits: support, a sequential multi-dataset streaming loader with background warm-up, and loguru-based logging with TensorBoard and W&B backends. HALE-WAM, Hale-VLM, HaloDiffusionLLM, and Halos-lift are all built on HaleBlocks.

Highlights

Plugin registries

@register_model, @register_loss, @register_sampler — one decorator adds a component to the registry; a YAML key selects it at runtime.

Strict configs

All experiments are pydantic-validated RunConfig objects. An unknown field is an error. Configs can inherits: base.yaml and override individual keys.

Attention à la carte

build_attention(variant, heads, kv_heads, …) — swap MHA, GQA, MQA, or block-causal attention. Masks and RoPE are applied in one place.

Stacks for every paradigm

GPTStack (causal), LGTStack (local-global + dual RoPE for diffusion/flow), DiTStack (adaLN-Zero for world models).

Streaming loader

Stream datasets sequentially up to a cap while the next warms up in a background thread. Bounded storage, no shuffle buffers, no full-dataset downloads.

33 LLM datasets

SmolLM2 pretrain stages (1–4), SFT (SmolTalk), and RL/DPO datasets, all as typed DatasetSpec entries in the LLM registry.

Quick start

uv add "hale-blocks @ git+https://github.com/basaanithanaveenkumar/HaleBlocks"
# or editable install:
uv add --editable /path/to/HaleBlocks
from hale_core.nn.layers import build_attention, build_attn_mask
from hale_core.nn.stacks import GPTStack, LGTStack
from hale_core.nn.backbones import build_backbone
from hale_core.nn.losses import token_nll
from hale_core.config import load_config
from hale_core.registry import register_model, register_loss

# Register a custom model variant
@register_model("my_model")
class MyModel(nn.Module):
    def __init__(self, cfg): ...

# Load and validate a YAML config (supports inherits:)
cfg = load_config("configs/my_experiment.yaml")
# Stream all SmolLM2 SFT datasets, 1000 samples each
from hale_core.data import build_llm_dataloader

loader = build_llm_dataloader(stage="finetune", samples_per_dataset=1000)
for sample in loader:
    print(sample.dataset, sample.prompt, sample.response)
