Abstract

Research code for language, diffusion and multimodal models tends to copy the same pieces, such as attention variants, mixture-of-experts layers, masks, configuration and training loops, into every new repository, where they slowly diverge. HaleBlocks factors these into one small library organised around a single rule: every component family is a named registry with a factory, and callers depend only on the factory.

It provides MHA/GQA/MQA with RoPE and QK-norm; dense, GeGLU and DeepSeek-style MoE feed-forward layers; causal, bidirectional and block-causal masks; GPT, local–global (Gemma-3 style) and AdaLN-Zero DiT stacks; tied token-to-logit backbones; token losses; optimisers including Muon; strict typed configuration with YAML inheritance; a trainer with DDP/FSDP helpers and experiment logging; and streaming data registries for the 33-dataset SmolLM2 recipe and a VLM mixture with an LRU media cache.

Highlights

Registries + factories

attention, ffn, backbone, loss, optimizer, logger, trainer, dataset, model, metric and config schema: register a name, never edit a call site.

Three stacks

GPT (pre-LN), LGT (RMSNorm, GQA, 5 local : 1 global, RoPE θ 10⁴/10⁶, p-RoPE) and DiT (AdaLN-Zero, time-conditioned).

Masks that compose

Bool masks, True = blocked: causal, bidirectional, sliding-window, and block-causal over [clean ; noisy] for block diffusion.

DeepSeek-style MoE

Shared + routed SwiGLU experts with a noisy top-k router, available in any stack via ffn_type: moe.

Strict configs

Pydantic sections with extra="forbid", inherits: deep-merge, and per-run directories with the resolved config dumped.

Data registries

SmolLM2: 15 pretrain, 14 SFT and 4 DPO datasets plus stage mixtures 1–4. VLM: sequential streaming with an LRU MediaCache.

Quick start

uv add "hale-blocks @ git+https://github.com/basaanithanaveenkumar/HaleBlocks.git"
# or, to develop:
git clone https://github.com/basaanithanaveenkumar/HaleBlocks && cd HaleBlocks
uv sync --extra dev && uv run pytest -q      # 114 passed
import torch
from hale_core.nn.backbones import build_backbone

lgt = build_backbone(32000, arch="lgt", d_model=256, n_heads=8, n_layers=6,
                     d_ff=1024, max_length=128, n_kv_heads=2)
dit = build_backbone(32000, arch="dit", d_model=256, n_heads=8, n_layers=6, d_ff=1024,
                     max_length=128, attn_type="bidirectional", use_time_cond=True)
logits = dit(torch.randint(0, 32000, (2, 64)), t=torch.rand(2))   # (2, 64, 32000)
